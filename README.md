# Site Pessoal

![](https://i.imgur.com/AEdcdKF.gif)

## Introdução

- Site Pessoal é uma página web que exibe **notícias do servidor de Minecraft**, **torneios** e outras informações pessoais do autor.
- O projeto possui **interatividade** e serve como vitrine para informações importantes e eventos do servidor.
- Desenvolvido com **HTML, CSS e JavaScript**, o site é totalmente responsivo e fácil de navegar.
